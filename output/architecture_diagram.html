node_entry — 入口路由

False → END（不支持格式）

node_pdf_to_md — PDF 解析 [条件节点]
上传 PDF 至 MinerU 远程 API → 轮询任务状态 → 下载解析结果 Markdown 文件
MinerU 轮询
▼

node_md_img — 图片提取 [当前跳过]
扫描 Markdown 图片引用 → VL 模型生成描述 → 上传 MinIO → 替换为 URL。当前因 SiliconFlow VL 超时暂时跳过
跳过 MinIO
▼
3
node_document_split — 语义切分
基于 Markdown 标题层级（# ## ###）智能分块，每块附带 book_title / content_type 等元数据前缀
RecursiveSplitter chunk
▼

node_book_meta_extract — 元数据提取
LLM 结构化提取：book_title / author / category / content_type / duration / highlights / faq / narrator / tags
LLM (qwen-plus) JSON 结构化
▼

node_item_name_recognition — 实体识别
LLM NER 识别条目名称 → 向量化 → 写入 Milvus tingbook_item_names 集合（去重）
LLM NER BGE-M3
▼

node_bge_embedding — 向量嵌入
BGE-M3 将 chunk.item_name + content 编码为 1024-dim dense + sparse 向量（batch）
BGE-M3 Dense + Sparse

查询流水线 QueryGraph · 11 Nodes · 2 Conditions

1
node_item_name_confirm — 实体消歧
LLM 从用户查询中提取书名/条目名 → 模糊匹配 Milvus item_name 集合 → 纠错/确认 → 设定 query_type
LLM Milvus 检索 纠错
▼ 条件分支 A
无 item_name 有 answer → node_answer_output
有 item_names → 并行检索
query_type=auto → node_intent_classify
2a
node_intent_classify — 意图分类 [条件节点]
LLM 判断意图：recommend / detail / note / search / qa → 路由至对应节点
LLM 分类
▼ 条件分支 B (query_type)
recommend → node_recommend
detail → node_book_detail
note → node_book_note
search/qa → 并行检索
3
多路召回 — 三路并行
三节点同时执行，结果汇聚至 node_rrf
Embedding 检索
query → BGE-M3 → 稠密+稀疏向量 → Milvus 混合检索 top-5
HyDE 检索
LLM 生成假设答案 → 嵌入 → Milvus 检索 top-5
Web MCP 搜索
阿里云百炼 MCP 协议调用网络搜索（可选补充）
▼ 汇聚
4
node_rrf — RRF 融合
Reciprocal Rank Fusion (k=60, w=1.0) 合并 Embedding + HyDE 结果 → 取 Top-5 候选
RRF 算法 去重融合
▼
5
node_rerank — 交叉编码精排
BGE-Reranker-v2-M3 对 Milvus + Web 结果打分 → 动态 Top-K 截断（分数 cliff 检测）
BGE-Reranker Cross-Encoder
▼
4a
专有节点 [意图分支旁路]
node_recommend / node_book_detail / node_book_note 直接生成答案，不经过检索排序
推荐 详情 笔记
▼
6
node_answer_output — 答案生成
构建 RAG Prompt（上下文 + 历史对话 + 结构化数据）→ LLM (qwen-plus) → 提取图片 URL → SSE 流式 / 非流式响应
LLM 生成 SSE MongoDB 持久化
■ END
LAYER 2-A 查询意图路由矩阵 — node_item_name_confirm 输出分支
query_type 路由目标 检索方式 业务说明
recommend node_recommend 向量聚合 + LLM 向量搜索多本书 → 聚合到书籍级 → LLM 生成推荐理由 / 适合人群 / 特色亮点
detail node_book_detail 全量拉取 + LLM 拉取某本书所有 chunks → 聚合元数据 → LLM 生成结构化详情摘要
note node_book_note 过滤向量检索 Milvus 过滤 content_type ∈ {notes, reviews, FAQ, 运营资料} → 返回听书笔记
search / qa 并行检索 → RRF → Rerank 混合检索 + HyDE + Web 三路并行召回 → RRF 融合 → BGE-Reranker 精排 → LLM 生成 RAG 回答
auto (无明确实体) node_intent_classify 同上 LLM 先做意图分类 → 按上述四类路由
